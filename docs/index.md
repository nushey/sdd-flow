# sdd-flow

Spec-driven software development workflows maintained by Nahuel Zeballos.
Plan changes, implement them in independent agent contexts, and verify the
result against explicit requirements. Standalone skills cover planning,
debugging, implementation, reviews, and writing.

The workflow combines reusable skills with specialized agents. It uses your
coding agent's tools and permissions; there is no project-operated server.

## Install

Use the single installer to select your coding client and installation scope:

```bash
curl -fsSL https://raw.githubusercontent.com/nushey/sdd-flow/main/scripts/install.sh | bash
```

Windows users can use the PowerShell installer described in the
[installation guide](https://github.com/nushey/sdd-flow/blob/main/INSTALL.md).
The installation guide also covers runtime and delegation requirements.
